# WinFormsLogger — Довідник розробника

Інструкції щодо налаштування, запуску та тестування застосунку WinFormsLogger.

## Вимоги

* .NET 10.0 SDK
* СУБД SQLite (керується автоматично через бібліотеку)
* Операційна система: Windows 10 / 11

## Структура проекту

* `WinFormsLogger/` — основний проект застосунку WinForms.
  * `DB/` — опис таблиць бази даних та репозиторіїв.
  * `Services/` — сервіси для трекінгу процесів, системних подій та синхронізації з сервером.
  * `Forms/` — додаткові інтерфейсні форми.
* `WinFormsLogger.Tests/` — модульні тести на базі xUnit та Moq.

## Налаштування та запуск

1. Переконайтеся, що встановлено потрібну версію .NET SDK.
2. Для побудови проекту виконайте команду:
   ```bash
   dotnet build
   ```
3. Для запуску застосунку:
   ```bash
   dotnet run --project WinFormsLogger
   ```

## Запуск тестів

Для запуску всіх юніт-тестів у рішенні:
```bash
dotnet test
```
