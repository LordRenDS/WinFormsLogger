# C# Developer Skills Matrix

## Junior
- Core C# syntax and basic .NET APIs.
- Understanding of Classes, Interfaces, and Inheritance.
- Basic LINQ and Generics.
- Git basics.

## Intermediate
- Proficiency in ASP.NET Core and EF Core.
- Deep understanding of Dependency Injection.
- Unit testing experience.
- Familiarity with SOLID and common Design Patterns.
- SQL and basic database design.

## Senior
- Advanced architectural patterns (Microservices, Event-Driven, Clean Architecture).
- Performance tuning and profiling (BenchmarkDotNet, Memory dumps).
- Cloud-native development (Azure/AWS).
- Mentoring and code review leadership.
- DevOps and CI/CD pipeline integration.
