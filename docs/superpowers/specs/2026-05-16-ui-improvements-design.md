# Дизайн-специфікація: Оновлення інтерфейсу користувача

**Дата:** 2026-05-16
**Тема:** UI-покращення, логування взаємодії з сервером, налаштування стовпців.

## 1. Мета
Покращити візуальне сприйняття даних у головному вікні програми, додати можливість моніторингу взаємодії з сервером у реальному часі та забезпечити гнучке налаштування інтерфейсу.

## 2. Архітектурні зміни та компоненти

### 2.1. Головне вікно (`Form1`)
- **Панель логів:** 
  - Замінити `dataGridView2` у нижній секції `splitContainer1` на `ListBox` з назвою `lstServerLogs`.
  - Реалізувати метод `LogServerEvent(string message)`, який додає запис із часом (наприклад, `[14:20:05] Sync started...`).
  - Налаштувати автоматичну прокрутку списку до останнього повідомлення.
- **Головне меню (`menuStrip1`):**
  - Додати верхній рівень меню **"Файл" (File)**:
    - Додати пункт **"Вихід" (Exit)**.
  - Додати верхній рівень меню **"Вигляд" (View)** (або "Опції" за бажанням користувача, але "Вигляд" є стандартним для UI-елементів):
    - Додати пункт **"Логи сервера" (Server Logs)** з можливістю встановлення "галочки" (CheckOnClick).
- **Керування видимістю:**
  - Прив'язати стан `Checked` пункту меню до властивості `splitContainer1.Panel2Collapsed`.

### 2.2. Таблиця процесів (`dataGridView1`)
- **Стовпці:**
  - `Id` (ID): AutoSize = DisplayedCells, HeaderText = "ID".
  - `ProcessName` (Process): AutoSize = DisplayedCells, HeaderText = "Процес".
  - `WindowsName` (Window Title): AutoSize = Fill, HeaderText = "Заголовок вікна".
  - `ProcessStart` (Start Time): AutoSize = DisplayedCells, HeaderText = "Початок".
  - `Duration` (Duration): AutoSize = DisplayedCells, HeaderText = "Тривалість (с)".
  - `IsSynced` (Synced): AutoSize = ColumnHeader, HeaderText = "Синхр.".
- **Поведінка:**
  - Ввімкнути можливість ручної зміни розміру стовпців користувачем.
  - Встановити `SelectionMode = FullRowSelect`.

### 2.3. Налаштування (`AppSettings` та `SettingsForm`)
- **AppSettings:**
  - Додати властивість `ShowServerLogs` (bool, default = true).
- **SettingsForm:**
  - Додати `CheckBox` для керування `ShowServerLogs`.
  - При збереженні налаштувань оновлювати стан інтерфейсу в `Form1`.

## 3. Потік даних (Data Flow)
1. `ServerSyncService` виконує запит -> викликає подію або метод у `Form1`.
2. `Form1` додає рядок у `lstServerLogs`.
3. При завантаженні `Form1` зчитує `AppSettings.ShowServerLogs` та ховає/показує панель.

## 4. План тестування
- Перевірити коректність відображення всіх стовпців у `dataGridView1`.
- Перевірити, що при зміні розміру вікна стовпець "Заголовок вікна" адаптується.
- Перевірити перемикання видимості нижньої панелі через меню та через налаштування.
- Перевірити, що пункт "Вихід" повністю закриває програму (навіть якщо вона була в треї).
